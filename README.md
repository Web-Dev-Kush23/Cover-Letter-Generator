# 📄 Cover Letter Generator

A simple and professional **Cover Letter Generator** built using **HTML, CSS, and JavaScript**.  

This application allows users to generate and preview customized cover letters and download them as PDF files using the **jsPDF** library.

---

## 🚀 Features

- ✍️ Generate Professional Cover Letters
- 👁️ Live Preview of Letter
- 📥 Download Cover Letter as PDF
- 🎨 Clean & Responsive UI
- ⚡ Fast and Lightweight Application
- 🖥️ Works Directly in Browser

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript**
- **jsPDF Library**

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/cover-letter-generator.git
```

### 2️⃣ Navigate to Project Directory

```bash
cd cover-letter-generator
```

### 3️⃣ Open the Project

Simply open the `index.html` file in your browser.

OR run using **Live Server** in VS Code.

---

## ▶️ Run with Live Server

1. Install the **Live Server** Extension in VS Code
2. Right-click on `index.html`
3. Click **Open with Live Server**

The app will run on:

```bash
http://127.0.0.1:5500
```
